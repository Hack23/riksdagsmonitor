## Alternative Approaches

### Option A: Machine Translation + Human Review
**Pros:**
- Faster initial output (days vs weeks)
- Lower cost
- Consistent terminology

**Cons:**
- Lower quality, especially for analytical prose
- Requires extensive human review
- May miss cultural nuances
- Risk of errors in political terminology

**Estimated effort:** 40-50 hours (translation + review)

### Option B: Strategic Language Selection
**Pros:**
- Focus resources on highest-value languages
- Achievable in shorter timeframe
- Maintain quality standards

**Cons:**
- Incomplete multi-language promise
- Miss some audience segments

**Recommended subset:** EN, SV, DA, NO, FI, DE, FR (7 languages = 28 files)  
**Estimated effort:** 42-56 hours

### Option C: Rolling Translation Program
**Pros:**
- Sustainable long-term approach
- New articles translated systematically
- Builds translation memory/glossary

**Cons:**
- Ongoing resource commitment
- Temporary language gaps

**Model:** Each new English article gets Swedish within 24h, Nordic within 1 week, others within 2 weeks

## Technical Implementation

### File Naming Convention
```
<date>-<article-slug>-<lang-code>.html

Examples:
2026-02-10-pm-eu-summit-en.html
2026-02-10-pm-eu-summit-sv.html
2026-02-10-pm-eu-summit-da.html
```

### Hreflang Structure
Each article must link to all available language versions:
```html
<link rel="alternate" hreflang="en" href=".../article-en.html">
<link rel="alternate" hreflang="sv" href=".../article-sv.html">
<link rel="alternate" hreflang="da" href=".../article-da.html">
...
<link rel="alternate" hreflang="x-default" href=".../article-en.html">
```

### Sitemap Updates
Each translated article requires:
```xml
<url>
  <loc>https://riksdagsmonitor.com/news/article-XX.html</loc>
  <lastmod>2026-02-10T09:00:00Z</lastmod>
  <changefreq>monthly</changefreq>
  <priority>0.8</priority>
  <xhtml:link rel="alternate" hreflang="en" href=".../article-en.html"/>
  <xhtml:link rel="alternate" hreflang="sv" href=".../article-sv.html"/>
  ...
</url>
```

### RTL Language Support
Arabic and Hebrew require:
```html
<html lang="ar" dir="rtl">
```

Plus CSS adjustments:
```css
[dir="rtl"] {
  text-align: right;
  /* Mirror layouts where appropriate */
}
```
