## 💡 Why EN + SV Default?

### Strategic Reasons

1. **Primary Audiences**
   - English: International researchers, journalists, EU observers
   - Swedish: Native citizens, parliament members, media

2. **Data Source**
   - riksdag-regering-mcp provides Swedish parliamentary data
   - English + Swedish have direct context understanding
   - Other languages would need translation layer

3. **Resource Efficiency**
   - 2 languages: Manageable generation time
   - 14 languages: 7× longer generation
   - 14 languages: 7× storage space

4. **Quality Control**
   - Direct content generation better than machine translation
   - Maintain The Economist editorial standards
   - Ensure political context accuracy

## 🔧 Technical Implementation

### Script: generate-news-enhanced.js

**Line 40-42**: Default configuration
```javascript
const languages = languagesArg
  ? languagesArg.split('=')[1].split(',')
  : ['en', 'sv'];  // Only EN + SV by default
```

**Line 150**: Multi-language loop
```javascript
for (const lang of languages) {
  console.log(`  🌐 Generating ${lang.toUpperCase()} version...`);
  // ... generates article in each language
}
```

**Lines 162-176**: All language titles
```javascript
const titles = {
  en: { title: `Week Ahead: ${dateRange.start} to ${dateRange.end}`, ... },
  sv: { title: `Vecka Framåt: ${dateRange.start} till ${dateRange.end}`, ... },
  da: { title: `Ugen Fremover: ${dateRange.start} til ${dateRange.end}`, ... },
  // ... all 14 languages
};
```

### What Each Language Gets

For each language in the `--languages` list:

1. ✅ **Language-specific title** (e.g., "Week Ahead" vs "Vecka Framåt")
2. ✅ **Language-specific subtitle**
3. ✅ **Proper lang attribute** (`<html lang="sv">`)
4. ✅ **hreflang tags** to all other language versions
5. ✅ **Language-specific metadata** (Open Graph, Twitter Cards)
6. ✅ **Schema.org in correct language**
7. ✅ **RTL layout** (for Arabic and Hebrew)
