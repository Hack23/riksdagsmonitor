4. Agent calls `riksdag-regering-get_ledamot` for each author
5. Human writes political analysis
6. Human translates to 13 languages

#### Proposed Semi-Automated Workflow

**Phase 1: Data Extraction** (Fully Automatable)
```javascript
async function extractMotionData(htmlFile) {
  // 1. Extract motion IDs from HTML
  const motionIds = extractMotionIds(htmlFile);
  
  // 2. Fetch document metadata via MCP
  const documents = await Promise.all(
    motionIds.map(id => fetchDocument(id))
  );
  
  // 3. Extract author IDs from XML
  const authorIds = documents.map(doc => 
    extractAuthorId(doc.text)
  );
  
  // 4. Fetch ledamot info via MCP
  const authors = await Promise.all(
    authorIds.map(id => fetchLedamot(id))
  );
  
  // 5. Create structured motion inventory
  return motions.map((doc, i) => ({
    dok_id: doc.dok_id,
    title: doc.titel,
    author: authors[i].namn,
    party: authors[i].parti,
    committee: doc.organ,
    date: doc.datum
  }));
}
```
