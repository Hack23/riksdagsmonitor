❓ 常见问题

这些文章是如何生成的？

每篇文章由代理工作流生成，该工作流针对 analysis/daily/YYYY-MM-DD/ 下发布的分析产物运行 AI-FIRST 管道。完整的提示合约位于 .github/prompts/。

文章有多新？

工作流在早晨、中午、傍晚和每周发布。最新文章位于列表顶部，每张卡片上都显示发布时间戳。

为什么有些文章只有英文？

分析首先用英文撰写，并在24小时内由 news-translate 工作流翻译。如果翻译缺失，请明天再来。

如何订阅源？

每种语言都有自己的 RSS/Atom 源（中文：/rss_zh.xml）。将 URL 添加到任何 RSS 阅读器以自动关注新文章。

来源可验证吗？

是的。每篇文章都链接到 GitHub 上的分析产物（analysis/daily/YYYY-MM-DD/stream/），并以稳定的 ID 引用议会、政府和机构的主要来源。
