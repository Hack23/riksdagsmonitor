    Canonical IMF WEO indicator IDs used by Riksdagsmonitor articles.

    Logical WEO surface — these are the codes article workflows cite as WEO:<code>. Some are addressable via the simple Datamapper JSON transport (see IMF_WEO_DATAMAPPER_AVAILABLE); the rest only live in the full WEO 9.0.0 SDMX dataflow (IMF.RES,WEO,9.0.0) and require weoSdmxPath with the IMF_SDMX_SUBSCRIPTION_KEY set. The WEO release cadence is twice a year (April + October) — bump DEFAULT_WEO_VINTAGE in imf/config/defaults.ts accordingly.
