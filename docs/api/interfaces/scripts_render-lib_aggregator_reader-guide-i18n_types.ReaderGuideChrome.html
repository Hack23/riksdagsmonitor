    ReadonlycolIcon

    colIcon: string

    Localized sr-only label for the icon column header. The icon column is visually decorative (the icon repeats meaning expressed in the next column) but assistive technology still needs a name for the column so users hear something distinct from the adjacent colReaderNeed header. Examples: "Icon" (en), "Ikon" (sv), "Icône" (fr), "アイコン" (ja).

    ReadonlydefaultReaderValue

    defaultReaderValue: string

    Generic localized fallback description used as the "reader value" cell for any analysis artifact that is not in the curated ../reader-guide.js#READER_GUIDE_ENTRIES list. Allows the Reader Intelligence Guide to render a row for every analysis artifact (icon + section anchor + description) so the table acts as a complete, navigable index of the article's analytical lenses.
