    Optional ReadonlybriefEntities

    briefEntities?: readonly string[]

    Pre-computed, story-specific keywords mined from the executive-brief (bill IDs, proposition refs, committee codes/reports, party codes, named entities). When present these are seeded FIRST so the highest-signal SERP tokens (HD03267, JuU28, SÄPO, Migrationsverket) lead the keyword string. Universal-Swedish identifiers (bill IDs, committee codes) survive untranslated across all 14 languages, so the same set is supplied to every locale's page. See scripts/render-lib/aggregator/seo/brief-extractor.ts.
