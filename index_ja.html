総合インテリジェンスプラットフォーム

CIAは4領域の45リスクルールと5つの分析フレームワークにより、政治的透明性を体系的に提供します。

🔍 リアルタイム監視

  • 349名の議員を自動追跡（履歴データ 2,494 名）
  • 個別投票記録 — 件を分析
  • 文書 500K+ 件を処理
  • 議員提案 — 件を追跡
  • 政府提案 10K+ 件を監視
  • 委員会業務を定量化（文書 — 件）

📊 連合の予測

  • 4つの選挙シナリオをモデル化
  • 履歴パターン分析（1971-2024）
  • 党規律の追跡
  • 離反確率の推定
  • 政権形成シミュレーション

✅ ファクトチェック基盤

  • 政治家発言と投票記録の照合
  • パーティプラットフォームの一貫性分析
  • 公約トラッキング
  • リアルタイム討論検証
  • 履歴説明責任指標

⚠️ リスク評価

  • 45の行動リスクルールを運用
  • MINOR/MAJOR/CRITICAL の重大度区分
  • 自動アラートシステム
  • 文脈を踏まえたトレンド分析
  • 透明性のある方法論

4領域にわたる45のリスクルール

  • 政治家レベル（20ルール）: 出席、投票一貫性、役割衝突、生産性
  • パーティーレベル (12 ルール): 連立規律、理念の乖離、内部対立
  • 委員会レベル（8ルール）: 立法生産性、党派的行き詰まり、専門家証言
  • 省庁レベル（5ルール）: 予算超過、政策失敗、説明責任の欠如

5つの分析フレームワーク

  • 時系列分析: 期間横断のトレンド検出
  • 比較分析: 政党/議員間ベンチマーク
  • パターン認識: 行動異常検知
  • 予測インテリジェンス: 選挙結果予測、連立モデリング
  • ネットワーク分析: 影響力マッピング、協調パターン

📊 Citizen Intelligence Agency データ製品

Riksdagsmonitor は、Citizen Intelligence Agency (CIA)— スウェーデンの議会データを処理して実用的なインテリジェンス製品を作成するオープンソースの OSINT プラットフォーム。

📈 リスク評価レポート

4領域の45リスクルールにより、政治家行動・政党規律・委員会有効性・省庁説明責任をリアルタイム分析します。

📅 季節別活動分析

Zスコア異常検知により四半期ごとの異常議会活動を特定し、2002年以降の基準線と比較します。

🎯 選挙サイクル・インテリジェンス

9回以上の選挙サイクル（1994-2034）でパフォーマンスを追跡し、予測リスク、政党階層分析、連立確率モデリングを提供します。

🔗 オープンデータ統合

すべてのインテリジェンス製品は公式のオープンデータソースに基づいています。可視化は夜間データパイプラインにより自動更新され、24時間キャッシュされます。

すべてのデータ製品は、スウェーデン議会のオープン データ API からのリアルタイム更新を備えた市民情報局プラットフォームを通じて利用できます。

🔗 データソースと統合

Riksdagsmonitor は、複数の信頼できるスウェーデンおよび国際的なデータ ソースを統合します。

🤖 AIによるニュース生成革命

Riksdagsmonitor のエージェント型ニュース生成パイプラインは、議会モニタリングのための世界初のフルAI駆動型「政治インテリジェンス・ニュースルーム」です。GitHub Copilot Coding Agent 経由で動作する Claude Opus を中核に、10個の専門ワークフロー（定期実行9本＋オンデマンド1本）が、自律的に高度な政治分析を生成します。単なる要約ではなく、情報源検証、複数政党への公平性、GDPRに準拠したOSINT手法に基づく構造化インテリジェンスとして提供します。
