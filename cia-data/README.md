# CIA Platform Data Files

This directory contains CSV data files from the CIA (Citizen Intelligence Agency) platform for Swedish Parliament (Riksdag) analysis.

## Data Sources

All CSV files are sourced from: https://github.com/Hack23/cia/tree/master/service.data.impl/sample-data

## Files

### Committee Performance Data
1. **distribution_committee_productivity_matrix.csv** - Committee productivity metrics over time
2. **view_riksdagen_committee_decisions.csv** - Committee decision records
3. **distribution_annual_committee_documents.csv** - Annual committee document counts
4. **view_riksdagen_committee_ballot_decision_party_summary.csv** - Committee voting patterns by party
5. **percentile_seasonal_activity_patterns.csv** - Seasonal activity patterns

## Update Frequency

These files should be updated periodically to reflect the latest parliamentary data. The Committee Performance Dashboard uses these files for visualizations.
