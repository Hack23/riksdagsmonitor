## Analysis

New Anti-Fraud Rules for Electronic Communications (2025/26:233):

- **SIM swapping prevention**: Telecom operators must implement identity verification before transferring SIM ownership
- **Number spoofing**: Rules against caller ID manipulation used in fraud schemes
- **Data retention**: Targeted extension of communications data retention for fraud investigation
- **EU directive implementation**: Implements amended Electronic Communications Code requirements

**Why it matters**: Telecom fraud (including vishing/phone scams, SIM swapping for bank account access) has grown significantly. Statistics from Polisen show telecom fraud as one of the fastest-growing crime categories 2023-2025.
