# Quantitative SWOT — Swedish Election Cycle 2026

## Scoring Methodology
- Scale: 1–10 for each item
- Weight: Strategic importance (1–3)
- Score = Value × Weight
- Strengths/Opportunities: Positive scores
- Weaknesses/Threats: Negative scores
