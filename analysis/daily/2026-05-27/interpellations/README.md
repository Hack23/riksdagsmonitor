## Key Findings Summary

1. **Climate governance vacuum**: Five interpellations in one week targeting substitute minister Johan Britz (L) document a factual policy vacuum — Styrmedelsutredningen delayed, 2030 targets in internal contradiction, Sweden's emissions have increased more than in any 15-year period.

2. **Welfare state erosion**: ~40 women's shelters closed; systematic sjukersättning denial to permanently incapacitated individuals.

3. **Constitutional accountability**: RF 1:2§ deployed against tax cuts; Prop. 2024/25:165 raising supermajority threshold challenged on democratic legitimacy grounds.

4. **Election signal**: 109 days to September 13, 2026. Election proximity multiplier 1.5× applied. Combined DIW top score: 8.1 (climate cluster).
