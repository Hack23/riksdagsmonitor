## Overview

This directory contains the full political intelligence analysis for the April 2026 monthly parliamentary review. The analysis covers the most intensive month of the 2025/26 Riksdag session — the spring budget peak — with 272 active propositions, 4,098 motions, and a 30-day period dominated by fiscal, criminal justice, and environmental legislation.
