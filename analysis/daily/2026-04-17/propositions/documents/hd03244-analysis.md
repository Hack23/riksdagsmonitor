# Per-Document Analysis: HD03244

**Title**: Nya krav på interoperabilitet vid datadelning inom den offentliga förvaltningen  
**Prop. Number**: 2025/26:244  
**Minister**: Erik Slottner (KD, Finansdepartementet)  
**Committee**: Trafikutskottet (TU)  
**Date**: 2026-04-16  
**Significance**: 7/10 🟩 HIGH

## Policy Summary

Proposition 2025/26:244 implements the EU Data Governance Act (DGA) requirements for Sweden's public sector. Key provisions:

1. **Mandatory API standards**: Government agencies, municipalities, and regions must publish data using EU-standard APIs by 2028
2. **Interoperability obligations**: Cross-agency data exchange must use standardized formats (reducing manual file transfers)
3. **Single digital gateway**: Contributes to Sweden's implementation of the EU Single Digital Gateway Regulation
4. **Oversight mechanism**: New compliance monitoring function at DIGG (Agency for Digital Government)

## Why It Matters

Sweden's public administration currently operates with significant data silos — the Swedish Tax Agency (Skatteverket), Social Insurance Agency (Försäkringskassan), Employment Service (Arbetsförmedlingen), and 290 municipalities each maintain separate systems that rarely communicate automatically. This creates massive administrative inefficiency: ~3 billion SEK annually estimated in redundant manual data handling.

HD03244 is the legislative backbone for Sweden's "Digitalt Kompetens" ambitions and EU Digital Decade compliance.

## Implementation Challenges

For 290 municipalities: The technical capacity varies enormously between Stockholm (population 980,000, large IT department) and rural municipalities like Dorotea (population 2,400, minimal IT resources). SKR will argue for state grants to cover implementation costs.

Timeline: 2028 target is achievable for large agencies; municipalities may need extensions.

## Competitive Context

Denmark, Estonia, and Finland have significantly more advanced interoperability frameworks. HD03244 closes a competitive gap in Sweden's public sector digitalization.
